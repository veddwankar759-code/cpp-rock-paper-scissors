# Rock Paper Scissors

A console-based Rock Paper Scissors game built in C++.

## Features

- Player vs computer gameplay
- Random computer choice
- Rock, Paper and Scissors options
- Winner and tie detection
- Invalid input handling

## Technologies Used

- C++

## How to Play

1. Enter `r` for Rock, `p` for Paper or `s` for Scissors.
2. The computer randomly selects its choice.
3. The game determines the winner.
